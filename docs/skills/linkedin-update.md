# linkedin-update — LinkedIn 콘텐츠 초안 생성 스킬

> 위치: `~/.claude/skills/linkedin-update/SKILL.md`

## 한 줄 요약

LinkedIn 포스트나 프로필 섹션(Experience, Projects, About) 의 초안을
한국어/영어/혼합으로 생성해 복붙 가능한 마크다운 + 게시 체크리스트로
출력하는 Claude Code 스킬.

## 만든 배경

LinkedIn 의 공식 API 는 개인 개발자에게 매우 제한적이라 자동 게시·프로필
편집이 사실상 불가능. 그렇다고 매번 빈 텍스트 박스에서 한국어/영어를
오가며 톤을 조정하는 것도 비효율. 결국 "**LLM 이 양식 갖춘 초안을 만들고,
사람이 복붙해서 게시**" 가 가장 현실적 워크플로라 판단해 그 과정을
스킬화함.

## 설계 결정

### 1. 자동 게시는 안 한다

자동 게시 시도 시 가능한 경로:
- LinkedIn Marketing API → 워크스페이스 승인 필요, 개인 불가
- Selenium/Playwright → ToS 위반, 계정 정지 위험
- 비공식 API → 깨지기 쉽고 윤리적 회색지대

→ 어차피 다 비추라 처음부터 시도 안 함. 출력의 마지막 줄이 항상 "게시
체크리스트" 인 이유.

### 2. 4가지 모드

| 모드 | 형식 |
|---|---|
| **post** | 타임라인 글 (100-300단어, 훅+본문+CTA+해시태그) |
| **experience** | 경력 한 줄 (3-6 임팩트 불릿) |
| **project** | 프로젝트 항목 (개요+기술+링크) |
| **about** | About 섹션 (200-400자 3단락) |

각 모드는 LinkedIn 의 실제 입력 위치/제약을 기준으로 길이/구조를 정함.

### 3. 컨텍스트는 매번 받는다 (캐싱 X)

처음엔 사용자 헤드라인·About 톤·최근 경력 등을 캐싱해두려 했으나,
- 본인 직책/회사 변경 시 캐시 stale 위험
- 매 글마다 톤이 다를 수 있음 (격식 vs 친근 vs 의견)

→ 매번 `mode`, `topic`, `language`, `tone` 을 묻는 게 일관성에 더 유리.
프로필 일반 정보는 [user-identity 메모리](../../../.claude/projects/...) 로
재사용.

### 4. 드래프트는 파일로 영구 보관

`~/.claude/drafts/linkedin/YYYY-MM-DD-<mode>-<slug>.md` 에 저장.

이유: LinkedIn 에 게시한 글은 사후 검색/편집이 불편함. 로컬에 원본을
보관해두면:
- 어떤 글을 언제 올렸는지 이력 추적
- 비슷한 주제 재작성 시 과거 톤 참고
- `status: posted` 필드로 게시 여부 표시

## 사용법

Claude Code 세션에서 자연어로 호출하면 됨:

```
> 링크드인에 이번 주에 만든 claude-resume 도구 자랑 글 올리고 싶어
```

스킬이 자동으로 트리거되면서 다음을 묻는다:
1. 모드 (post / experience / project / about)
2. 소재 (위 자연어로 이미 알려줬으면 그대로 사용)
3. 언어 (ko / en / both)
4. 톤 (pro / friendly / thought-leader)

응답으로 받는 것:
- 채팅에 전체 드래프트 출력 (복사 편의)
- 드래프트 파일 경로
- LinkedIn 의 어느 위치에 붙여넣을지 안내 + 미리보기 체크리스트

## 본명/필명 분리 원칙

LinkedIn 은 **본명 채널** (`Yongtak Kim`). 따라서:
- VR/게임/엔터테인먼트 색채 표현은 일반화 (예: "VRChat" → "VR")
- 개인 취미 활동은 LinkedIn 에 올리지 않음 (별도 채널)
- 본명을 알리고 싶지 않은 작업물은 LinkedIn 이 아닌 다른 곳에 게시

상세 가이드는 메모리 시스템의 `user-identity` 항목 참조.

## ChatGPT Pro 와의 활용 조합

사용자가 ChatGPT Pro 구독 중. 자동화에 직접 쓸 순 없지만(소비자 채팅
인터페이스), **2차 검토용으로 유용**:
- 이 스킬로 초안 생성 → ChatGPT 에 붙여서 "톤 다듬어줘" 요청
- 두 모델 출력 비교 후 마음에 드는 표현 골라 합치기

특히 공개 노출이 큰 글(이력서급 콘텐츠) 은 이 2차 검토 워크플로 권장.
